# StockBot — 台股 / 美股技術分析訊號工具

一個給**一般使用者**的選股輔助工具：在網頁儀表板上看 K 線與技術指標、查當前買賣訊號（附白話理由）、
用歷史資料回測策略、並概覽自己的投資組合。

> ⚠ **僅供參考，不構成投資建議，也不會自動下單。** 所有持股/資金都由你自己輸入，工具不內嵌任何個人財務數字。

---

## 一、快速開始（一鍵啟動）

**前提**：電腦已裝 Python 3.10 以上（安裝時請勾選 *Add python.exe to PATH*）。

**只要雙擊 `啟動儀表板.bat`** 即可。它會自動：
1. 檢查 Python；2. 首次自動建立虛擬環境 `.venv`、安裝所需套件（需幾分鐘、要連網）；
3. 啟動儀表板，瀏覽器自動開啟 http://localhost:8501 。

之後再雙擊會偵測到環境已就緒、**直接開啟**；`requirements.txt` 有更新時會自動重裝。
（手動安裝/啟動方式見下方第三節。）

## 二、設定（都可選）

1. **台股資料想更穩**：複製 `.env.example` 為 `.env`，填入 `FINMIND_TOKEN`。
   不填也能跑（台股自動退回 yfinance 的 `.TW`）。
2. **要看投資組合**：複製 `portfolio.yaml.example` 為 `portfolio.yaml`，填入你的持股與現金。
3. **想改觀察清單或參數**：編輯 `config.yaml`（觀察標的、指標/風控/回測參數）。
   或直接在儀表板左側欄「➕ 新增標的」，免改檔。

## 三、手動安裝 / 啟動（進階，選用）

不想用一鍵 `.bat`，也可手動操作：

```powershell
# 1. 建立虛擬環境（已建好可略過）
python -m venv .venv

# 2. 安裝套件
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. 啟動儀表板
.venv\Scripts\streamlit run dashboard/app.py
```

## 四、五個分頁在做什麼

| 分頁 | 內容 |
|------|------|
| **K線+指標** | K 線疊 EMA／布林通道，下方 MACD、RSI；自動標出買賣箭頭與停損/停利線。右上工具列可手畫趨勢線。 |
| **當前訊號** | 所有觀察標的目前是買/賣/觀望，**附白話理由**（為什麼進出場）。 |
| **回測績效** | 用歷史資料模擬這套策略：總報酬、年化、Sharpe、最大回撤、勝率…並和「買進持有」對照。每個數字旁有一句話說明。 |
| **投資組合** | 讀你的持股，顯示現值、損益、配置比例圓餅。可在頁內直接新增/移除庫存。 |
| **策略說明** | 用白話解釋每一種策略怎麼買怎麼賣、適合什麼行情。 |

左側欄可隨時切換：**標的、策略、回測長度（6mo～max）、K線週期（日/週/月線）**。

## 五、四種策略，適合不同行情

| 策略 | 適合行情 | 一句話 |
|------|---------|--------|
| **EMA + MACD + RSI** | 有明顯趨勢 | 順勢動能：均線判方向、MACD 抓動能、RSI 防過熱。 |
| **Fibonacci 回撤** | 上升趨勢中回檔 | 順勢低接：回踩 0.5–0.618 黃金回撤區間時買進。 |
| **Golden Cross 50/200** | 長期持有 | 50 日線上穿 200 日線買、跌破賣；交易少、吃大波段。 |
| **Bollinger 布林通道** | 上下震盪盤 | 均值回歸：跌到下軌反彈買、回到中軌停利。 |

> 在「策略說明」分頁可看到每支策略的完整白話說明；切換策略後，K線箭頭、當前訊號、回測都會一起換。

## 六、命令列掃描（進階，選用）

不開儀表板、只想快速看訊號：

```powershell
.venv\Scripts\python.exe scanner.py                # 印出所有標的當前訊號
.venv\Scripts\python.exe scanner.py --only-signals # 只印有買/賣訊號的
```

## 七、重要說明

- 指標與回測**只使用當下與過去資料**，嚴防偷看未來（look-ahead bias）。
- 策略未必勝過「買進持有」——強多頭中短線頻繁進出常落後，**請用回測分頁對照後再決定**。
- 通知功能（Discord / Email 等）尚未開放，介面已預留。
